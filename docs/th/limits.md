นี่คือตัวตรวจสอบคำประกาศแบบออฟไลน์ ไม่ใช่ตัวควบคุมการป้องกัน เครื่องทดสอบของช่างไฟฟ้า บริการค้นหาการเดินสาย หรือการเชื่อมต่อ Home Assistant ที่สั่งการได้

- ค่ารวมเพียงค่าเดียวไม่สามารถคำนวณกำลังพร้อมกันที่แน่นอนของโหลดไม่ทราบค่าสามตัวได้ การคาดเดาทางสถิติเป็นค่าประมาณ ไม่ใช่การวัดที่เหมาะกับระบบป้องกัน
- ผู้ดูแลเป็นผู้ระบุขอบเขต แหล่งกำเนิด ทิศทางของเครื่องหมาย และคำประกาศการสอบเทียบ คำประกาศเท็จอาจทำให้ระบบกายภาพที่ไม่ถูกต้องดูถูกต้องเชิงโครงสร้าง
- `complete` หมายถึงครบถ้วนเมื่อเทียบกับโหนดใบที่ประกาศ ไม่ใช่การเดินสายที่ตรวจสอบอย่างอิสระ เครื่องหมายรีเซ็ตจากแหล่งข้อมูลเป็นหลักฐานที่เชื่อถือ ไม่ใช่การรับรองตัวอุปกรณ์
- รองรับ W, kW, Wh, kWh, V และ A เราไม่จำลองกำลังรีแอกทีฟ/กำลังปรากฏ พีชคณิตสามเฟส การอิ่มตัวของ CT หม้อแปลงแรงดัน การวนกลับของตัวนับ หรืออัตราค่าไฟ
- สมาชิกของผลรวมคือมิเตอร์โดยตรง ไม่ใช่ผลรวมอื่น ผลรวมกำลังต้องมีเวลาสอดคล้องกัน ผลรวมพลังงานต้องมีจุดเริ่มต้นตัวนับร่วมที่ระบุชัดและตัวอย่างที่สอดคล้องกัน
- ค่าเป็นจำนวนทศนิยมลอยตัวที่มีขอบเขตจำกัด นี่ไม่ใช่บัญชีเลขฐานสิบสำหรับเรียกเก็บเงิน ตัวคูณการสอบเทียบถูกบันทึก แต่ไม่ถูกนำไปใช้คำนวณ
- ตรวจเฉพาะตัวอย่างปัจจุบันและตัวอย่างก่อนหน้าที่อาจมีหนึ่งรายการ ไม่ใช่ฐานข้อมูลย้อนหลัง ตัวตรวจจับความผิดปกติหรือการเลื่อนค่า หรือการตรวจสอบความสมบูรณ์ของตัวนับทั้งหมด
- เวลาต้นทางของ HA ต้องมีอยู่จริงและแสดงเวลาที่ได้การวัดจริง เวลาแคชรับข้อมูลไม่ถูกยอมรับแทนอย่างเงียบ ๆ
- การโหลด JSON/YAML มีขอบเขตจำกัด API ไลบรารี `audit` คาดหวัง `Contract` ที่สร้างจากตัวแยกวิเคราะห์ อย่าสร้าง dataclass ที่ผิดรูปแบบตามอำเภอใจจากออบเจ็กต์ที่ไม่เชื่อถือ
- อินพุตไฟล์ยอมรับเฉพาะไฟล์ปกติ ปฏิเสธลิงก์สัญลักษณ์ที่ส่วนท้ายของพาธ FIFO อุปกรณ์ และไดเรกทอรี เปิดแบบไม่บล็อกและตรวจตัวบรรยายไฟล์ที่เปิดแล้วก่อนอ่าน แพลตฟอร์มที่ไม่มี `O_NOFOLLOW` และ `O_NONBLOCK` จะปฏิเสธไฟล์ ให้ใช้ `ha_meter_contracts.reader.loads_document` กับสตริงที่จำกัดขนาดแล้วแทน ลิงก์ในไดเรกทอรีแม่ไม่ใช่ขอบเขต sandbox ขีดจำกัดไบต์ยังใช้แม้ไฟล์ขยายระหว่างอ่าน
- ผลผ่านไม่ได้พิสูจน์การทำงานจริงของรีเลย์ วาล์ว มอเตอร์ การไหลของปั๊ม หรือความปลอดภัยทางไฟฟ้า ไม่มีการซ่อมหรือลองซ้ำอัตโนมัติ

อินพุตและเอาต์พุตอาจมี ID เอนทิตีและเวลาที่ผู้ดูแลระบุ เก็บสัญญา/ข้อมูลส่งออกจริงไว้เป็นส่วนตัว ที่เก็บนี้มีเฉพาะตัวอย่างสังเคราะห์ โปรแกรมไม่อัปโหลดข้อมูล แต่การส่งรายงานต่อไปยังบริการภายนอกเป็นการตัดสินใจของผู้ดูแล
