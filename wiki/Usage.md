# Usage

Install Python 3.11+, then install the source package in a virtual environment. Run `ha-meter-contracts check CONTRACT --json --lang en`. Exit 0 means no error/warning, 1 means audit findings, 2 means invalid input. Use a fixed `--at` time for reproducible examples.
