# Использование

Установите Python 3.11+ и пакет из исходников в виртуальное окружение. Запуск: `ha-meter-contracts check CONTRACT --json --lang ru`. Код 0 — нет ошибок и предупреждений, 1 — находки аудита, 2 — неверный ввод. Для повторяемых примеров задайте `--at`.

[Full guide / Полное руководство](https://github.com/ha-homelab/ha-meter-contracts/blob/main/docs/ru/usage.md)
