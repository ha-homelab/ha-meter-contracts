Python 3.11+ ইনস্টল করুন, তারপর ভার্চুয়াল পরিবেশে সোর্স প্যাকেজ। `ha-meter-contracts check CONTRACT --json --lang en` চালান। প্রস্থান 0 মানে ত্রুটি/সতর্কতা নেই, 1 অন্তত একটি ত্রুটি বা সতর্কতা, 2 অবৈধ ইনপুট। শুধু তথ্যমূলক ফলেও 0 ফেরে। পুনরুৎপাদনযোগ্য উদাহরণে স্থির `--at` সময় ব্যবহার করুন।
